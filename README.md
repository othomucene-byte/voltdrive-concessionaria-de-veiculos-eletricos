# VoltDrive — Concessionária de Veículos Elétricos

Plataforma completa de e-commerce e configurador para veículos 100% elétricos, com comparador de autonomia, reserva de test drive e gestão de frota.

## 🚀 Tecnologias
- **React 19 + TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Vite & Edge Deploy (Vercel)**
- **E2B Sandbox MicroVM Isolation**

## 📦 Como Executar Localmente
```bash
# 1. Instalar dependências
npm install

# 2. Iniciar servidor de desenvolvimento
npm run dev

# 3. Compilar para produção
npm run build
```
